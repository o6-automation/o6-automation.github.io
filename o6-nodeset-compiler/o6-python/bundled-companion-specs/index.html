List of bundled companion specs¶

o6\Python dependency declarations such as -e ns0 -e di select XML shipped with ncc. No download is needed during compilation. At runtime, shorthand uses the companion namespaces shipped with o6\Python. Your own generated versions belong in your project and use custom dependency declarations. See compatibility and dependency usage.

The bundle contains 136 canonical definitions and three compatibility definitions. The source-only entry irdi_v1_01_0 has no corresponding runtime module and cannot be used as bundled shorthand.

Historical models¶

Names such as irdi_v1_00 and irdi_v1_0_0 select different model releases even when they share a Model URI. irdi_v1_00 also loads a supplement that supplies missing references. You must still declare other transitive dependencies explicitly. Use a custom dependency when you supply your own model version and runtime package.

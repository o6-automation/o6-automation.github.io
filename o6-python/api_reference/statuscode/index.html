StatusCode¶

Canonical path: o6.StatusCode

StatusCode ¶

Bases: IntFlag

OPC UA StatusCode (32-bit bitfield).

Severity (bits 31-30) | SubCode (bits 29-16) | InfoBits (bits 15-0). Members are generated from deps/open62541/tools/schema/StatusCode.csv.

Because this is an enum.IntFlag, the bitwise and containment operators work directly: StatusCode.BAD in status tests the severity, and info bits can be layered onto a sub-code. A value of 0 is GOOD with no info bits, which is what an unset DataValue.status reads back as.

See StatusCode.
